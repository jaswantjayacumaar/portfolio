# Portfolio — Jaswant Jayacumaar

Personal portfolio of Jaswant Jayacumaar — Data Analyst, London.
Analytics platforms, marketing automation and production LLM tooling.

Built with Next.js 16 (App Router), TypeScript and Tailwind CSS 4.
Fully static — no server, no database.

## Develop

```bash
npm run dev
```

## Build

```bash
npm run build
```

Deployed on Vercel; every push to `main` auto-deploys.
